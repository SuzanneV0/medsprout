# Medsprout

A medication-tracking web app with reminders, refill tracking, taper schedules, family profiles, label scanning, and a side-effect log.

**[Visit Medsprout](https://www.medsprout.app)**

## Project focus

Medsprout explores how to make everyday medication information easier to organize and use. The project brings together product planning, interface design, content structure, and hands-on web development.

## Explore the repository

- `index.html`, `styles.css`, and `app.js`: the main web experience.
- `scan.js` and `pills.js`: supporting medication and scanning functionality.
- `manifest.webmanifest` and `sw.js`: progressive web app configuration and service worker.
- `native/`: companion native project files.

## Technology

HTML, CSS, JavaScript, and progressive web app features, with Vercel hosting configuration.

## Project status

An independent project under ongoing development. The repository and live site may evolve as features are refined. This README is a project overview, not a clinical validation or a guarantee of every feature's availability.
