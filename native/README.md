# Medsprout phone app (Capacitor)

This folder wraps the Medsprout website (the repository root) as an installed Android app, and later an iPhone app, using [Capacitor](https://capacitorjs.com).

**Why:** a website can only show reminders while it's open or in the background. Inside the phone app, `native.js` hands reminders to the phone's own scheduler (`@capacitor/local-notifications`), so they arrive when Medsprout is closed, after a restart, and with **Mark taken** / **Snooze** buttons. Data still stays only on the device.

The website is the single source of truth. Never edit `native/www` or `android/app/src/main/assets/public`; they're copied from the site by `npm run sync`.

## What's here

| Path | What it is |
|---|---|
| `capacitor.config.json` | App id `app.medsprout`, name, notification icon and colour |
| `android/` | The Android Studio project (generated by Capacitor, with Medsprout icons and splash screens) |
| `scripts/copy-web.mjs` | Copies the website into `www/` for bundling |
| `scripts/make-android-icons.js` | Redraws every Android icon, notification icon and splash screen from the Medsprout logo |
| `../native.js` | Native reminder scheduler; does nothing on the website |

## Build and try it on an Android phone

One-time setup (about 10 GB of downloads):

1. Install **[Android Studio](https://developer.android.com/studio)**. It includes the Java runtime and Android SDK that Capacitor needs.
2. Open Android Studio once and let it finish downloading the SDK.

Every time you want a fresh build:

```bash
cd native
npm install          # first time only
npm run sync         # copy the website in and update the Android project
npm run open:android # opens the project in Android Studio
```

In Android Studio, plug in your phone with **USB debugging** on (Settings → About phone → tap *Build number* 7 times → Developer options → USB debugging) and press **Run ▶**.

## Things to check on a real phone

- **Settings → Turn on notifications**, then **Send a test**, then close the app completely. The test should still arrive.
- **Android 12 and later:** if Settings shows *"For on-time reminders, allow Medsprout to set alarms"*, tap **Allow alarms**. Without it, Android may deliver reminders a few minutes late.
- Some phone brands (Samsung, Xiaomi, OnePlus…) aggressively stop background apps. If reminders are late, set Medsprout's battery usage to **Unrestricted**.

## Publishing

- **Google Play:** needs a Google Play developer account (one-time US$25). Build a signed release bundle in Android Studio (*Build → Generate Signed App Bundle*). Keep the signing key safe; you can't update the app without it. The app id `app.medsprout` can't be changed after the first upload.
- **Apple App Store:** needs a Mac with Xcode and an Apple Developer account (US$99/year). On the Mac: `npm install @capacitor/ios`, `npx cap add ios`, `npm run copy-web`, `npx cap sync ios`, then `npx cap open ios`.

Both stores will ask for a privacy policy URL (use `https://www.medsprout.app/#privacy`) and a data-safety declaration. Medsprout collects no personal data. Only the website's anonymous visit counts exist, and the phone app doesn't send them because it runs from local files.
